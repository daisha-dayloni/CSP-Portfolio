# CSP-Portfolio
7 projects I worked on during the 2nd semester that I am most proud of.
1. ATM - Create a global variable balance. This program defines a function 3 functions that simulate transactions in an atm
2. Calculator Simple Math - Create a program that prompts users to enter two numbers, an operator, and prints the result of the operation
3. Interior Design Asistance - Help someone choose an inspo photo to decorate their room and sure its in their budget.
4. Movie Theatre - Write a function that collects the user’s age as input and prints what types of movie the user can see at the movie theatre
5. Pokemon Game - telling us what the pet did wether it's train, rest, and exit.
6. Supermarket - It finds the index of a specific item, applies a discount percentage to all item prices, and filters out the items that cost less than or equal to a specified maximum price, storing them in a separate list.
7. Chicago Streets - This code filters and identifies Chicago streets where hourly traffic volume meets or exceeds a specific, user-defined threshold.
